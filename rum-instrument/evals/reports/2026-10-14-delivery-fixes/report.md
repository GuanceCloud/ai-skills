# RUM 交付评审修复与收敛

日期：2026-10-14。本轮只修复整体评审确认的问题与相关说明，不继续模拟器或后台入库验收，不更新本机已安装 Skill，不提交、推送或发布。

## 修复结果

| 发现 | 最终行为 | 回归证据 |
|---|---|---|
| 嵌套 JSON 配置写入错误 | JSON `rum.clientToken` 写入嵌套对象；无点键保持顶层，properties 中的点仍是字面字符。保留其他字段；遇到同名字面点键、非对象中间节点、对象/数组目标或重叠父子路径时提前拒绝 | 验证消费 `config.rum.clientToken` 得到新值；共享兄弟路径写入与 resume 不重复换码；冲突不修改文件、不读取授权码 |
| 旧入口在配置解析前换码 | 新旧命令入口复用 `inspect_secret_sink` 的无凭据渲染检查；移除计划入口重复实现，保留旧参数兼容 | 无效 JSON、非对象 JSON、非法 UTF-8、路径形状冲突在站点查询与读取授权码前拒绝 |
| UniApp H5 重复识别 | 同目录 HTML 入口归属 UniApp；保留旁边独立 Web 工程 | 同时覆盖有 package.json 的 UniApp、无 package.json 的 HBuilderX、独立兄弟 Web 目录 |

JSON 点分路径仅支持对象属性，不自动迁移已有字面点键，也不替换对象或数组来制造 Token 叶子。旧错误布局需按应用实际消费方式修复，不能静默覆盖；这些约束已经写入接入契约。

## 收敛

- Android、iOS/tvOS、macOS 适配器采用共享隐私规则：普通 SDK URL/query 字段可用，具体敏感数据和项目明确排除项才需要过滤与实际载荷验证。
- 最终交付逐目标说明实际应用 ID、已知应用名称、接收地址/模式、测试或生产配置；应用名称不得从 service 推断。源码接入、运行验证、后台入库分别报告证据和状态，合成 ID 与本地抓包接收器须明确标注。
- 新旧凭据流程共用同一配置格式检查，保持现有 CLI 和恢复状态兼容；未进行无关的大规模重构。
- README、安装接入入口及配置契约同步更新。
